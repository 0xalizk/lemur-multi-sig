# Checkups

Raw audit transcripts behind [`../review.md`](../review.md):
[`checkup_0/`](checkup_0/) paper audit (theory / implementation /
field lenses), [`checkup_1/`](checkup_1/) per-claim fact-check on
`review.md` (197 atomic claims), [`checkup_2/`](checkup_2/)
repo-wide integrity sweep. Each round had an independent reviewer
pass.

This folder is meant for agents to load into their context for tips,
tricks, and pitfalls to avoid when working with the Lemur artifact.
The load-bearing audit/review findings have been folded into
[`review.md`](../review.md); items that remain open are summarised
in [§10 "Open issues"](../review.md#sec-10). Minor / non-load-bearing
items the auditors surfaced live in the per-round ledgers
([`open-issues.md`](open-issues.md), [`unresolved.md`](unresolved.md))
and are flagged but not individually applied.
